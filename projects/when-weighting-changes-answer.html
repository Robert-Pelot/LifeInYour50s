When the Weighting Changes the Answer

By Robert Pelot  •  September 22, 2026
THE MOST IMPORTANT PART OF A MODEL IS OFTEN THE PART PEOPLE DO NOT SEE.

In this project, the hidden assumptions were the weights used to combine social, environmental, and health vulnerability into one composite result.

This started as a Tableau final project, but it became a useful case study in data modeling.

The project asked a practical question: if we want to understand community vulnerability in Upstate South Carolina, how do we combine different kinds of risk without pretending they are all measured the same way?

That question matters because poverty, environmental burden, chronic disease, infrastructure barriers, and related indicators may all contribute to vulnerability, but they are not naturally comparable. A useful model has to make unlike measures comparable enough to analyze together, while still making it clear that the final result depends on design decisions.

1) Comparing vulnerability dimensions

The first dashboard separates social vulnerability, environmental burden, and health outcomes. This matters because it prevents a composite score from hiding the fact that different areas may be driven by different underlying conditions.

2) Building a fixed composite model

The second dashboard combines the three dimensions into a fixed composite model using a baseline weighting of 40% social / 30% environmental / 30% health. It also shows the dominant risk driver instead of presenting only one total score.

3) Showing that the assumptions matter

The strongest part of the project is the interactive explorer. The viewer can change the weights assigned to social, environmental, and health factors, and the system updates the map and dominant-driver results accordingly.

That turns the dashboard into something more analytical than a static report. It makes the assumptions visible and shows that changing the weighting can change the answer.

A COMPOSITE SCORE IS NEVER JUST DATA. IT IS DATA PLUS A DECISION RULE.

Exposing the decision rule makes the dashboard more analytical, more transparent, and more honest.

What this demonstrates technically

  • Data integration across multiple sources tied to census-tract geography
  • Geospatial mapping in Tableau
  • Normalization and tract-level calculations
  • Composite-score construction
  • Dominant-driver logic and category comparison
  • Scenario analysis through user-controlled parameters
  • Storytelling through a structured Tableau story

Why it belongs on the portfolio site

This is stronger than a generic Tableau homework item because it demonstrates more than software familiarity. It shows analytical reasoning, model design, data transformation, visualization, and the ability to communicate uncertainty instead of hiding it.

It also makes a larger point that applies well beyond Tableau: when a model combines unlike risks, the result is shaped not only by the data but also by the rule used to combine the data.
